# 🌦️ Weather Forecast App

A simple and responsive **Weather Forecast Web Application** built with **Python and Flask**.

Users can search for any city and view its current weather along with a **5-day weather forecast** using real-time data from the OpenWeather API.

---

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Current temperature
- 🤗 Feels-like temperature
- 💧 Humidity information
- 💨 Wind speed
- 🌤️ Current weather condition
- 📅 5-day weather forecast
- 📱 Responsive design
- 🔐 API key secured using environment variables
- ⚠️ Error handling for invalid cities and API issues

---

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Flask
- ☁️ OpenWeather API
- 🎨 HTML5
- 💅 CSS3
- 📦 Requests
- 🔐 Python-dotenv
